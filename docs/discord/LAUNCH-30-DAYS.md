# Développer la communauté — proposition sur 30 jours

Ce calendrier est une proposition, pas une série d'événements déjà programmés.

## Avant l'ouverture

- Installer les textes et tester les permissions avec un compte membre.
- Faire essayer installation, import et support à 3–5 volontaires.
- Obtenir l'invitation permanente ; l'ajouter au README et à VAV.
- Préparer une démonstration de 45–60 secondes : avatar → changement → release → historique.

## Semaine 1 — Petit groupe

- Inviter personnellement les personnes déjà intéressées, sans envoi massif.
- Poser une question : « Quel problème souhaites-tu résoudre avec VAV ? »
- Répondre aux demandes avec les informations réellement disponibles ; ne pas promettre un support 24/7.

## Semaine 2 — Retours utiles

- Regrouper les doublons et compléter les guides.
- Partager une courte démonstration dans les espaces qui autorisent la promotion.
- Rechercher quelques testeurs volontaires, sans attribuer automatiquement des droits particuliers.

## Semaine 3 — Montrer les progrès

- Publier les corrections réellement livrées et remercier leurs auteurs avec leur accord.
- Proposer une session de questions uniquement si une personne de l'équipe peut l'animer.
- Expliquer pourquoi une suggestion est retenue ou reportée.

## Semaine 4 — Simplifier

- Garder les salons utiles ; éviter d'en ajouter pour donner une impression d'activité.
- Examiner le délai de réponse, les demandes résolues et les membres qui reviennent.
- Choisir quelques améliorations réalisables pour la suite.

## Texte de présentation pour un espace autorisé

« Je développe VRC Avatar Vault, une application Windows pour suivre les changements et versions de ses avatars VRChat, consulter des informations techniques et lire les données OSC. Je cherche des retours sur l'installation et l'utilité des outils. Le code et les versions sont ici : https://github.com/KioQc/vrc-avatar-vault. »

Invitation permanente : https://discord.gg/evvAZQzjPt. Ce texte n'a été envoyé à aucune communauté.

## Suivi hebdomadaire, sans collecte intrusive

Noter : nombre de demandes ouvertes/résolues, délai médian de première réponse, bugs confirmés/corrigés et questions récurrentes. Ne pas installer de suivi des messages privés ni exporter la liste des membres pour du démarchage.
