# 👋 Bienvenue sur VAV • VRC Avatar Vault

VAV est une application desktop pour suivre le développement de tes avatars VRChat : changements, versions, données techniques, snapshots, outils Unity et lecture OSC.

**Pour commencer**

1. Lis le règlement.
2. Télécharge VAV depuis la source officielle : https://github.com/KioQc/vrc-avatar-vault/releases/latest
3. Consulte les guides d'installation et de connexion.
4. Choisis les notifications que tu souhaites recevoir, si le sélecteur de rôles est disponible.

**Besoin d'aide ?** Ouvre un sujet dans le forum support. Pour une erreur reproductible, utilise bugs. Pour une idée, utilise suggestions.

Tu peux aussi présenter ton projet et expliquer comment tu utilises VAV. Les retours précis nous aident à améliorer l'application.

VAV est un projet communautaire indépendant, non affilié à VRChat. L'équipe ne te demandera jamais ton mot de passe, un code 2FA ou un jeton de connexion.
