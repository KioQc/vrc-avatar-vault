# 📜 Règlement

1. Respecte les autres membres. Pas de harcèlement, discrimination, menaces ou attaques personnelles.
2. Utilise le bon salon et évite le spam, les pings répétés et les messages privés d'assistance non sollicités.
3. Ne partage pas de mots de passe, cookies, jetons, codes 2FA ou informations personnelles. Masque ces éléments dans tes captures et journaux.
4. Partage uniquement les avatars, fichiers et ressources que tu as le droit de diffuser. Pas de contenu volé ni de demande de contournement d'accès.
5. Garde les publications adaptées à une communauté technique : pas de contenu sexuel explicite ni d'images choquantes.
6. Signale les comportements problématiques à la modération. N'organise pas de règlement de comptes public.
7. Télécharge VAV via les liens officiels. Ne présente pas un exécutable modifié comme une version de l'équipe.

Selon la situation, la modération peut retirer un message, avertir, limiter temporairement l'accès ou exclure un membre. Une contestation peut être adressée calmement à l'équipe.
