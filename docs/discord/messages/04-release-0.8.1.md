# 🚀 VRC Avatar Vault 0.8.1

La version 0.8.1 est disponible pour Windows x64.

**Téléchargement officiel**
https://github.com/KioQc/vrc-avatar-vault/releases/tag/v0.8.1

**Première installation / ancienne version**
Télécharge `VRC-Avatar-Vault-0.8.1-Setup.exe` et installe-le au même emplacement que VAV.

**Déjà en 0.8.0 ?**
Ouvre Settings → GitHub automatic updates, puis Check GitHub now. Une fois le téléchargement vérifié, utilise Install & restart après avoir enregistré ton travail.

La recherche et le téléchargement automatiques sont activés par défaut et restent désactivables. L'installation demande ta confirmation et crée une sauvegarde de la base.

Tes données locales restent dans leur emplacement existant. Pour une copie externe complète, utilise aussi l'export du coffre.

Un souci ? Ouvre un sujet dans support avec ta version de VAV, ton Windows et le message d'erreur.
