# 📝 Patch notes — 0.8.1

**Distribution**

- Le dépôt et les versions GitHub sont publics.
- Le manifeste de mise à jour et l'installateur sont accessibles sans compte GitHub.
- L'installateur est signé pour le système de mise à jour Tauri.

**Mises à jour dans VAV**

- Recherche au démarrage puis toutes les 15 minutes si activée.
- Téléchargement automatique désactivable.
- Vérification de signature avant installation.
- Installation sur confirmation, avec sauvegarde SQLite préalable.

Les fonctions de mise à jour ont été introduites en 0.8.0 ; 0.8.1 finalise leur distribution publique. Aucun changement du format des données locales.

**Vérifications**
Compilation Windows, signature, refus d'un fichier altéré et téléchargement public vérifiés. La suite précédente de 97 tests concerne le même code fonctionnel. Le parcours de mise à jour complet n'a pas été exécuté sur les données personnelles d'un utilisateur.
