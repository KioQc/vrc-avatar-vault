# 🚧 Problèmes connus et limites

**Publication des versions**
La compilation GitHub Actions est actuellement bloquée par un problème de facturation du compte. Les versions publiées restent téléchargeables ; cela ne t'empêche pas d'utiliser VAV.

**Avertissement Windows**
La signature de mise à jour Tauri n'est pas un certificat Windows Authenticode. Windows peut donc afficher un avertissement d'éditeur. Vérifie la provenance officielle avant toute installation.

**Accès VRChat**
Un avatar privé ou supprimé peut être inaccessible à ton compte. Les champs absents restent inconnus : VAV ne doit pas inventer une performance ou une plateforme.

**OSC**
Un autre outil peut déjà utiliser le port d'écoute. VAV affiche l'erreur sans interrompre cet outil. Le panneau sert à lire les données ; il ne pilote pas les paramètres de ton avatar.

**Plateformes**
La livraison vérifiée est Windows x64. Les builds Linux et macOS ne sont pas validés ici.

Pour signaler un autre problème, utilise bugs avec les étapes permettant de le reproduire. Ce message sera mis à jour quand une limite est corrigée.
