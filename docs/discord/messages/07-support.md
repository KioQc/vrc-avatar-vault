# 🆘 Demander de l'aide

Crée un sujet par problème. Un titre comme « OSC : aucune donnée reçue sur Windows 11 » aide davantage que « ça marche pas ».

Copie ce modèle :

```text
Version de VAV :
Version de Windows :
Fonction concernée :
Ce que j'essaie de faire :
Ce qui se passe :
Message d'erreur exact :
Ce que j'ai déjà essayé :
Capture ou journal nettoyé, si utile :
```

Choisis le tag Installation, Mise à jour, VRChat API, OSC, Unity ou Données.

Ne joins pas ta base complète ou ton projet Unity par défaut. Masque les noms de dossiers personnels, identifiants sensibles et tokens dans les journaux.

L'aide se fait dans le sujet lorsque possible, pour que la solution serve aux autres. L'équipe n'offre pas de délai de réponse garanti. Quand le souci est réglé, indique la solution et demande le tag Résolu.
