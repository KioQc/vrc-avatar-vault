# 🐛 Signaler un bug

Vérifie d'abord les problèmes connus et les sujets existants. Ajoute tes informations à un signalement identique plutôt que de le dupliquer.

```text
Titre : [fonction] problème en une phrase
Version VAV / Windows :
Étapes pour reproduire :
1.
2.
3.
Résultat attendu :
Résultat obtenu :
Fréquence : toujours / parfois / une fois
Impact : bloquant / gênant / visuel
Message d'erreur ou capture nettoyée :
```

Tags de suivi de l'équipe : À examiner → Informations nécessaires → Confirmé → En cours → Corrigé.

« Confirmé » ne promet pas une date de correction. Quand un correctif est publié, l'équipe indique la version concernée.

Ne publie pas les détails exploitables d'une faille de sécurité dans un forum public : contacte d'abord le fondateur pour convenir d'un échange privé, sans envoyer de secrets.
