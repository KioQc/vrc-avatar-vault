# 💡 Proposer une amélioration

Une suggestion par sujet. Explique le problème que tu rencontres avant de décrire un bouton ou une nouvelle page.

```text
Titre de l'idée :
Mon besoin / problème :
Comment je fais aujourd'hui :
Amélioration proposée :
Exemple concret :
À qui cela servirait :
```

Avant de créer un sujet, recherche les idées similaires. Une réaction sur une idée existante aide à estimer l'intérêt sans multiplier les doublons.

Tags de suivi : À discuter, Retenue, En développement, Livrée, Non retenue.

Les votes éclairent les priorités, mais ne constituent pas une promesse de livraison. L'équipe prend aussi en compte la faisabilité, les bugs et le temps disponible.
