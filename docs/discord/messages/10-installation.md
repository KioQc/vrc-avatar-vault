# 📚 Guide — Installer et mettre à jour VAV

1. Ouvre https://github.com/KioQc/vrc-avatar-vault/releases/latest
2. Télécharge l'installateur Windows `Setup.exe` de la version publiée.
3. Ferme VAV si l'installateur le demande, puis installe au même emplacement.
4. Relance l'application.

WebView2 est nécessaire pour afficher l'interface. En cas d'erreur, garde son texte exact pour le support.

Depuis VAV 0.8.0, Settings → GitHub automatic updates permet de rechercher les nouvelles versions. Avec la recherche activée, VAV vérifie au démarrage puis toutes les 15 minutes.

Le téléchargement et la vérification peuvent être automatiques. **Install & restart** reste une action volontaire : enregistre tes brouillons avant de l'utiliser.

Une ancienne version dépourvue de ce panneau nécessite une première installation manuelle. Ne désinstalle pas VAV en supprimant ses données pour faire une simple mise à jour.
