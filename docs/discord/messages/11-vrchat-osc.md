# 📚 Guide — VRChat et OSC

**Connexion et import**
Dans l'application Windows, ouvre Settings → VRChat account. Connecte-toi et complète le challenge 2FA si demandé. Utilise ensuite Import Avatar avec l'identifiant `avtr_…`, vérifie l'aperçu et confirme.

Ton compte doit avoir accès à l'avatar. Un refus d'accès n'est pas forcément un bug de VAV.

**Lire les données en jeu**
Active OSC dans VRChat, puis ouvre VRChat Center → OSC live dans VAV et démarre l'écoute. Le port par défaut est 9001. Si tu as changé la configuration OSC, vérifie que les ports correspondent.

Si le port est occupé, regarde quels autres outils OSC tu utilises avant de modifier leur configuration. VAV ne les ferme pas automatiquement.

La configuration OSC décrit les paramètres et leurs adresses ; le panneau live montre les messages effectivement reçus. Ce sont deux vues différentes.

Ne partage jamais ton mot de passe VRChat, tes cookies, ton code 2FA ou ton token dans Discord.
