# 🎉 Bienvenue dans la communauté VAV

Le serveur accueille les utilisateurs et créateurs d'avatars qui souhaitent suivre VRC Avatar Vault, obtenir de l'aide et contribuer à son amélioration.

Pour démarrer :

- découvre VAV dans bienvenue ;
- télécharge la dernière version depuis releases ;
- consulte guides ;
- pose une question dans support ou partage une idée dans suggestions.

Pour les premiers retours, nous aimerions surtout savoir : l'installation fonctionne-t-elle, les informations d'avatar sont-elles compréhensibles, et quel outil t'aide réellement dans ton travail ?

Présente ton utilisation de VAV si tu le souhaites. Aucun achat ni projet complet à partager pour participer.

Merci de garder les signalements précis et respectueux : une capture nettoyée et quelques étapes peuvent suffire à faire avancer une correction.
